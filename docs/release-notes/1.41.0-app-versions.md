# Release notes for admin -> App Versions - 1.41.0

Store / in-app `UpdatePrompt` release notes for version **1.41.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.41.0:
- Two new languages: Portuguese (Portugal) and Portuguese (Brazil), plus the Brazilian real (BRL).
- Pro and Business can be bought in Brazilian reais.
- Incomes saved or deleted offline now sync reliably.
- Help: a receipt deposit is described as already paid, not as money you get back.
```
