# Release notes for admin → App Versions — 1.17.2

Store / in-app `UpdatePrompt` release notes for version **1.17.2**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

**Self-contained**, for the same reason as 1.17.1: 1.17.0 shipped the
import-from-any-bank feature with no way to open it, and depending on what is
live in Play a user may arrive here from 1.16.1 or 1.17.0 having never seen the
feature described. So these blocks describe it, not only this version's fix.

**The undo/re-import fix is deliberately omitted.** It shipped server-side and
took effect for everyone without an app update, so listing it as something you
get by updating would be misleading. It is in `CHANGELOG.md` instead.

---

## en

```
New in 1.17.2:
• Import a statement from any bank. Pick "Detect automatically" and, if we don't recognise the format, AI works out which column is the date, the amount and the description. You're asked once per account before anything is sent, and you can still map the columns yourself.
• You can see which columns it matched and correct one with a tap — it can get a column wrong.
• Spreadsheet (XLSX) statements are now accepted. Reading PDF statements with AI requires Pro.
• Fixed: after choosing a file the screen no longer looks dead while your statement is being read — it can take about half a minute the first time we see a format.
• Transfers show both accounts' balances, your most frequent routes as chips, and a date field — and you can change an existing transfer's accounts.
```

## ru

```
Нового в 1.17.2:
• Импорт выписки из любого банка. Выберите «Определить автоматически» — и если формат нам незнаком, AI разберётся, где дата, сумма и описание. Согласие спрашивается один раз на счёт, а разметить колонки вручную можно по-прежнему.
• Видно, какие колонки он сопоставил, и одну можно поправить одним тапом — он может ошибиться.
• Принимаются выписки в виде таблиц (XLSX). Чтение PDF через AI требует Pro.
• Исправлено: после выбора файла экран больше не выглядит мёртвым, пока выписка разбирается — в первый раз для незнакомого формата это занимает около полуминуты.
• В переводах видны балансы обоих счетов, частые направления показаны чипами, появилось поле даты — и у существующего перевода можно изменить счета.
```

## ua

```
Нове у 1.17.2:
• Імпорт виписки з будь-якого банку. Виберіть «Визначити автоматично» — і якщо формат нам незнайомий, AI визначить, де дата, сума й опис. Згоду запитуємо один раз на рахунок, а розмітити колонки вручну можна й далі.
• Видно, які колонки він зіставив, і одну можна виправити одним дотиком — він може помилитися.
• Приймаються виписки у вигляді таблиць (XLSX). Читання PDF через AI потребує Pro.
• Виправлено: після вибору файлу екран більше не виглядає мертвим, поки виписка розбирається — уперше для незнайомого формату це триває близько півхвилини.
• У переказах видно баланси обох рахунків, часті напрямки показані чипами, з'явилося поле дати — і в наявному переказі можна змінити рахунки.
```

## pl

```
Nowości w 1.17.2:
• Import wyciągu z dowolnego banku. Wybierz „Rozpoznaj automatycznie" — a jeśli nie rozpoznajemy formatu, AI ustali, która kolumna to data, kwota i opis. Pytamy o zgodę raz na konto, a kolumny nadal możesz zmapować samodzielnie.
• Widzisz, które kolumny dopasował, i jedną poprawisz jednym dotknięciem — może się pomylić.
• Obsługujemy wyciągi w arkuszach (XLSX). Czytanie PDF przez AI wymaga Pro.
• Poprawione: po wybraniu pliku ekran nie wygląda już na zawieszony, gdy wyciąg jest czytany — przy nieznanym formacie zajmuje to około pół minuty.
• Przelewy pokazują salda obu kont, najczęstsze kierunki jako chipy oraz pole daty — a w istniejącym przelewie możesz zmienić konta.
```

## es

```
Novedades en 1.17.2:
• Importa un extracto de cualquier banco. Elige «Detectar automáticamente» y, si no reconocemos el formato, la IA deduce qué columna es la fecha, el importe y la descripción. Te lo preguntamos una vez por cuenta antes de enviar nada, y siempre puedes asignar las columnas tú.
• Puedes ver qué columnas ha emparejado y corregir una con un toque: puede equivocarse.
• Aceptamos extractos en hoja de cálculo (XLSX). Leer extractos PDF con IA requiere Pro.
• Corregido: al elegir un archivo la pantalla ya no parece bloqueada mientras se lee el extracto — la primera vez con un formato nuevo tarda medio minuto aproximadamente.
• Las transferencias muestran el saldo de ambas cuentas, tus rutas más frecuentes como chips y un campo de fecha — y puedes cambiar las cuentas de una transferencia ya creada.
```

## fr

```
Nouveautés de la 1.17.2 :
• Importez un relevé de n'importe quelle banque. Choisissez « Détection automatique » : si le format nous est inconnu, l'IA détermine quelle colonne contient la date, le montant et la description. Nous vous le demandons une fois par compte avant tout envoi, et vous pouvez toujours mapper les colonnes vous-même.
• Vous voyez les colonnes qu'elle a associées et pouvez en corriger une d'un geste — elle peut se tromper.
• Les relevés en tableur (XLSX) sont acceptés. Lire un relevé PDF avec l'IA nécessite Pro.
• Corrigé : après le choix d'un fichier, l'écran ne semble plus figé pendant la lecture du relevé — la première fois avec un format inconnu, cela prend environ trente secondes.

```

## de

```
Neu in 1.17.2:
• Importieren Sie einen Kontoauszug von jeder Bank. Wählen Sie „Automatisch erkennen" — kennen wir das Format nicht, ermittelt die KI, welche Spalte Datum, Betrag und Beschreibung enthält. Wir fragen einmal pro Konto, bevor etwas gesendet wird, und Sie können die Spalten weiterhin selbst zuordnen.
• Sie sehen, welche Spalten zugeordnet wurden, und korrigieren eine mit einem Tipp — die Zuordnung kann falsch sein.
• Auszüge als Tabelle (XLSX) werden akzeptiert. Das Lesen von PDF-Auszügen mit KI erfordert Pro.
• Behoben: Nach der Dateiauswahl wirkt der Bildschirm nicht mehr wie eingefroren, während der Auszug gelesen wird — beim ersten Mal mit einem unbekannten Format dauert das etwa eine halbe Minute.
• Überweisungen zeigen die Salden beider Konten, Ihre häufigsten Wege als Chips und ein Datumsfeld — und Sie können die Konten einer bestehenden Überweisung ändern.
```

## be

## nl

```
Nieuw in 1.17.2:
• Importeer een afschrift van elke bank. Kies "Automatisch herkennen" — kennen we het formaat niet, dan zoekt AI uit welke kolom de datum, het bedrag en de omschrijving is. We vragen het één keer per account voordat er iets wordt verzonden, en je kunt de kolommen nog altijd zelf toewijzen.
• Je ziet welke kolommen zijn gekoppeld en corrigeert er één met een tik — hij kan een kolom misinterpreteren.
• Afschriften als spreadsheet (XLSX) worden geaccepteerd. PDF-afschriften met AI lezen vereist Pro.
• Opgelost: na het kiezen van een bestand lijkt het scherm niet meer vast te zitten terwijl je afschrift wordt gelezen — de eerste keer bij een onbekend formaat duurt dat ongeveer een halve minuut.
• Overboekingen tonen het saldo van beide rekeningen, je meest gebruikte routes als chips en een datumveld — en je kunt de rekeningen van een bestaande overboeking wijzigen.
```
