# Release notes for admin -> App Versions - 1.21.0

Store / in-app `UpdatePrompt` release notes for version **1.21.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

**The automatic sign-in is stated with all three of its conditions, every time.**
It is Android-only, it needs a device genuinely restored from a backup of the old
one rather than set up fresh, and an end-to-end-encryption user still enters their
passphrase. Dropping any of the three to make the sentence shorter turns a true
claim into a complaint waiting to happen — a user who sets up a fresh phone and is
asked to log in would be right to say the note lied.

**Nothing here claims the restore has been proven end to end.** It has not been
executed on real hardware; the wording is what the feature does when it works,
hedged with "if", not a promise that it always will.

**The memory fix is described as what the user gets, not as what was wrong.**
"The app was holding three copies of your photo in memory" is accurate and
alarming; it is stated as scanning being lighter and starting faster.

---

## en

```
New in 1.21.0:
- Moving to a new Android phone? If you set it up from a backup of your old one, the app signs you in by itself on first launch. If you use end-to-end encryption you still enter your passphrase - that is what keeps your data private.
- Scanning a receipt is lighter and starts faster. The app was sending the camera's full-resolution photo and holding extra copies of it in memory while it worked.
- Groceries are no longer filed under the bottle-deposit category, and the app no longer keeps repeating that mistake on later receipts from the same shop.
- Investments, projects, debts and budgets now load in the web app, not only on your phone.
- A half-finished confirmation in the Telegram bot survives a server restart instead of being lost.
```
