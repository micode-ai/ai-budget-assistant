# Release notes for admin → App Versions — 1.13.0

Store / in-app `UpdatePrompt` release notes for version **1.13.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

---

## en

```
New in 1.13.0:
• Inflation Shield — forecasts prices from your receipts and tells you what to stock up on now, how much to buy, where, and your estimated savings; tracks total saved so far.
• Financial Wrapped — a swipeable year-in-review card deck built from your own data; share as text or an image.
• Community Price Map (Pro) — crowdsourced "where's cheapest" search built from everyone's anonymized receipts, with a store map.
• AI chat can now search individual receipt line items ("how much did I spend on beer?") and add items to your shopping list.
• Move an expense to a different account.
• Plus a cleaner account switcher (Active/Archived/Deleted), a shopping-list empty-state fix, and several reliability fixes.
```
