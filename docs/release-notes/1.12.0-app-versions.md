# Release notes for admin → App Versions — 1.12.0

Store / in-app `UpdatePrompt` release notes for version **1.12.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

---

## en

```
New in 1.12.0:
• Smart Shopping List — shared, offline-first lists; compare your basket to find the cheapest store from your receipts (Pro); restock reminders, deal alerts and a store map.
• One shopping button on the home screen combines the shopping list and purchase requests.
• Location: address search now prioritises places near you and opens on your position; recent places are remembered; near-me search now works on the web too.
• Receipts scanned via the Telegram/WhatsApp/Slack bots now appear on the expense map.
• AI chat: any member of a shared account can make a chat shared (not just the owner); fixed a duplicated-message glitch.
• Lower Pro pricing ($4.99/mo, $29.99/yr) plus several crash and reliability fixes.
```
