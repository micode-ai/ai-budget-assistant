# Release notes for admin -> App Versions - 1.25.0

Store / in-app `UpdatePrompt` release notes for version **1.25.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**A minor, not a patch.** This release carries a new feature (the invite offer,
ABA-489) alongside the Wallet layout fix, so it is 1.25.0 rather than 1.24.1 —
the feature had landed after the v1.24.0 tag and was still unreleased.

**The invite offer is described with its limits.** Once every 60 days, gone after
two dismissals, and only after a friend has actually paid. Announcing "the app
will suggest inviting friends" without those bounds promises exactly the nagging
the design avoids.

**The fix names the condition.** It only showed with several accounts — the row
fitted a single-account layout — so a note saying "fixed the Wallet screen" would
have half the users hunting for something they never saw.

## en

```
New in 1.25.0:
- Once a friend has paid you back for their share of a bill, the app offers to invite them — at most one offer every 60 days, and it stops for good after you dismiss it twice.
- Fixed: with several accounts, the Wallet screen's rate-alerts entry stretched across the screen and covered the start of the exchange history.
```
