# Release notes for admin -> App Versions - 1.31.0

Store / in-app `UpdatePrompt` release notes for version **1.31.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit**; the
builder that produced this file asserts it per locale.

**The categorize review leads**, because it is what a new user meets first: a
month of scanned receipts with no categories. The duplicate warning and the
wrong-category fix follow, as the two receipt problems reported during testing.

**Deliberately NOT listed:** the service splits (ABA-591, ABA-592), the wiki
(ABA-578/579/584), test fixes (ABA-577), the marketing site (ABA-570-574, ABA-580),
the one-time category backfill and the fixes from the acceptance run (ABA-600),
which describe states no user of this version will see.

---

## en

```
What's new in 1.31.0:
- Sort everything without a category in one pass: suggested categories you keep, change or create.
- A warning before the same receipt is added twice - checked before any AI request is spent.
- Groceries no longer land in an unrelated category when you scan a receipt.
- Say "undo" in the chat to revert the last thing it saved.
- Share a shopping list by link, search price history, and import Money Manager and Wallet exports.
```

## ru

```
Что нового в 1.31.0:

```
