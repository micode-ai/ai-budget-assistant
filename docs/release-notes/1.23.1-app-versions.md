# Release notes for admin -> App Versions - 1.23.1

Store / in-app `UpdatePrompt` release notes for version **1.23.1**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**No `app_versions` row was created for this version** - it is a layout fix with
no new feature, so there is nothing to invite anyone to update *for*, and the
1.23.0 row stays the one the in-app prompt serves. The copy below is here for the
Play "What's new" field and for the record.

**The note names the phones it affects.** "Three-button navigation" is the whole
condition: on a gesture-navigation phone the sheets were fine, and a note that
just said "fixed buttons on sheets" would have half the users looking for a
problem they never had.

**It says eight sheets, not "some sheets".** The same fixed padding had been
copy-pasted eight times; naming the count and the three a user is most likely to
have hit is more useful than a vague "various fixes".

---

## en

```
Fixed in 1.23.1:
- On phones with three-button navigation, the buttons at the bottom of pop-up sheets were hidden behind the navigation bar and could not be tapped. Eight sheets were affected, among them the "What's New" note, the Safe-to-Spend breakdown and the receipt category picker.
```
