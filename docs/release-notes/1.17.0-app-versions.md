# Release notes for admin → App Versions — 1.17.0

Store / in-app `UpdatePrompt` release notes for version **1.17.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

The admin fix (ABA-389) is deliberately omitted — it is not something a user of
the app can see.

---

## en

```
New in 1.17.0:
• Import a statement from any bank. If we don't recognise the format, AI works out which column is the date, the amount and the description. You're asked once per account before anything is sent, and you can still map the columns yourself.
• You can see which columns it matched and correct one with a tap — it can get a column wrong.
• Spreadsheet (XLSX) statements are now accepted. Reading PDF statements with AI requires Pro.
• Transfers now show both accounts' balances, your most frequent routes as chips, and a date field — and you can change an existing transfer's accounts.
• Fixed: Revolut CSV exports are now detected automatically, and picking your bank from the list no longer leaves every row unticked.
```

## ru

```
Нового в 1.17.0:
• Импорт выписки из любого банка. Если формат нам незнаком, AI разбирается, где дата, сумма и описание. Согласие спрашивается один раз на счёт, а разметить колонки вручную можно по-прежнему.
• Видно, какие колонки он сопоставил, и одну можно поправить одним тапом — он может ошибиться.
• Принимаются выписки в виде таблиц (XLSX). Чтение PDF через AI требует Pro.
• В переводах теперь видны балансы обоих счетов, частые направления показаны чипами, появилось поле даты — и у существующего перевода можно изменить счета.
• Исправлено: выгрузки Revolut в CSV определяются автоматически, а после выбора банка из списка строки больше не остаются без галочек.
```

## ua

```
Нове у 1.17.0:
• Імпорт виписки з будь-якого банку. Якщо формат нам незнайомий, AI визначає, де дата, сума й опис. Згоду запитуємо один раз на рахунок, а розмітити колонки вручну можна й далі.
• Видно, які колонки він зіставив, і одну можна виправити одним дотиком — він може помилитися.
• Приймаються виписки у вигляді таблиць (XLSX). Читання PDF через AI потребує Pro.
• У переказах тепер видно баланси обох рахунків, часті напрямки показані чипами, з'явилося поле дати — і в наявному переказі можна змінити рахунки.
• Виправлено: вигрузки Revolut у CSV визначаються автоматично, а після вибору банку зі списку рядки більше не залишаються без позначок.
```

## pl

```
Nowości w 1.17.0:
• Import wyciągu z dowolnego banku. Jeśli nie rozpoznajemy formatu, AI ustala, która kolumna to data, kwota i opis. Pytamy o zgodę raz na konto, a kolumny nadal możesz zmapować samodzielnie.
• Widzisz, które kolumny dopasował, i jedną poprawisz jednym dotknięciem — może się pomylić.
• Obsługujemy wyciągi w arkuszach (XLSX). Czytanie PDF przez AI wymaga Pro.
• Przelewy pokazują teraz salda obu kont, najczęstsze kierunki jako chipy oraz pole daty — a w istniejącym przelewie możesz zmienić konta.
• Poprawione: eksporty CSV z Revolut są rozpoznawane automatycznie, a po wybraniu banku z listy wiersze nie są już odznaczone.
```

## es

```
Novedades en 1.17.0:
• Importa un extracto de cualquier banco. Si no reconocemos el formato, la IA deduce qué columna es la fecha, el importe y la descripción. Te lo preguntamos una vez por cuenta antes de enviar nada, y siempre puedes asignar las columnas tú.
• Puedes ver qué columnas ha emparejado y corregir una con un toque: puede equivocarse.
• Aceptamos extractos en hoja de cálculo (XLSX). Leer extractos PDF con IA requiere Pro.
• Las transferencias muestran ahora el saldo de ambas cuentas, tus rutas más frecuentes como chips y un campo de fecha — y puedes cambiar las cuentas de una transferencia ya creada.
• Corregido: los exportes CSV de Revolut se detectan automáticamente, y elegir tu banco de la lista ya no deja todas las filas sin marcar.
```

## fr

```
Nouveautés de la 1.17.0 :
• Importez un relevé de n'importe quelle banque. Si le format nous est inconnu, l'IA détermine quelle colonne contient la date, le montant et la description. Nous vous le demandons une fois par compte avant tout envoi, et vous pouvez toujours mapper les colonnes vous-même.

• Les relevés en tableur (XLSX) sont acceptés. Lire un relevé PDF avec l'IA nécessite Pro.
• Les virements affichent désormais le solde des deux comptes, vos trajets les plus fréquents sous forme de puces et un champ de date — et vous pouvez changer les comptes d'un virement existant.
• Corrigé : les exports CSV de Revolut sont détectés automatiquement, et choisir votre banque dans la liste ne laisse plus toutes les lignes décochées.
```

## de

```
Neu in 1.17.0:
• Importieren Sie einen Kontoauszug von jeder Bank. Wenn wir das Format nicht kennen, ermittelt die KI, welche Spalte Datum, Betrag und Beschreibung enthält. Wir fragen einmal pro Konto, bevor etwas gesendet wird, und Sie können die Spalten weiterhin selbst zuordnen.
• Sie sehen, welche Spalten zugeordnet wurden, und korrigieren eine mit einem Tipp — die Zuordnung kann falsch sein.
• Auszüge als Tabelle (XLSX) werden akzeptiert. Das Lesen von PDF-Auszügen mit KI erfordert Pro.
• Überweisungen zeigen jetzt die Salden beider Konten, Ihre häufigsten Wege als Chips und ein Datumsfeld — und Sie können die Konten einer bestehenden Überweisung ändern.
• Behoben: CSV-Exporte von Revolut werden automatisch erkannt, und nach der Auswahl Ihrer Bank aus der Liste sind die Zeilen nicht mehr alle abgewählt.
```

## nl

```
Nieuw in 1.17.0:
• Importeer een afschrift van elke bank. Kennen we het formaat niet, dan zoekt AI uit welke kolom de datum, het bedrag en de omschrijving is. We vragen het één keer per account voordat er iets wordt verzonden, en je kunt de kolommen nog altijd zelf toewijzen.
• Je ziet welke kolommen zijn gekoppeld en corrigeert er één met een tik — hij kan een kolom misinterpreteren.
• Afschriften als spreadsheet (XLSX) worden geaccepteerd. PDF-afschriften met AI lezen vereist Pro.
• Overboekingen tonen nu het saldo van beide rekeningen, je meest gebruikte routes als chips en een datumveld — en je kunt de rekeningen van een bestaande overboeking wijzigen.
• Opgelost: CSV-exports van Revolut worden automatisch herkend, en na het kiezen van je bank uit de lijst staan de regels niet meer allemaal uitgevinkt.
```
