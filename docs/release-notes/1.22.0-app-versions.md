# Release notes for admin -> App Versions - 1.22.0

Store / in-app `UpdatePrompt` release notes for version **1.22.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

**The QR code is described by what it shows, not only by what it does.** It is a
names-only picker: no amount, no currency, no payment status. Saying "scan to see
your share" without that would imply the code exposes the bill to whoever points
a camera at it, which it does not.

**Individual links are stated as still working.** The QR replaces nothing - it is
the in-person path beside the existing one - and a user who reads "one QR code
instead of links" and then needs to bill an absent friend should not think the
feature was taken away.

**The "What's New" note is described with its limits.** One card at a time, it can
be dismissed, and it never appears before the first transaction. A release note
that promises "we now tell you about new features" without those bounds sets up
the expectation of a digest that this deliberately is not.

**The last line does not claim a speed-up.** The internal work of this release is
file splitting and de-duplication; it changes no behaviour, so it is listed as
exactly that and nothing more.

## en

```
New in 1.22.0:
- Splitting a bill in person? Show one QR code: everyone at the table scans it, picks their own name and gets their own share with the payment link. The code shows names only - no amounts, and not who has already paid. Sending an individual link to someone who is not there works as before.
- The app now points out a feature you may not have found yet - one card at a time, you can dismiss it, and never before you have added your first transaction. The full list is in Settings.
- Plus internal cleanups with no visible change.
```
