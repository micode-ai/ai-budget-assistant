# Release notes for admin -> App Versions - 1.23.0

Store / in-app `UpdatePrompt` release notes for version **1.23.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

**The bot correction grammar is not in the store text.** "Send them as text, one
per message" is as far as it goes - the exact syntax (`3 = 14,69`, `3 -`,
`+ Bread 5,99`) is taught by the bot's own hint the moment you enter that mode,
and a store note listing five command forms reads as a manual, not as news.

**The rate alert is described as hourly and one-shot.** Both bounds are load
bearing: without "checked hourly" a user expects a live ticker and reads a
20-minute delay as a bug, and without "fires once" they expect to keep being told
while the rate sits above their target.

**The shared-account transfer line says what it changes, not that anything was
hidden.** The balance always counted those transfers; only the list did not show
them. Phrasing it as "now you can see them" without that would read as a privacy
change rather than as the list catching up with the balance it explains.

**Nothing claims the receipt price check re-runs on a corrected price.** It does
not - correcting a line changes what is saved and the category split, and that is
all the note promises.

## en

```
New in 1.23.0:
- Scanned a receipt and a price came out wrong? Fix it before saving: correct a price, rename a line, delete one that was never there, add one that was missed. Every line is shown now, and the category split is recalculated from your corrections.
- The same corrections work in Telegram, WhatsApp and Slack - tap "Items" and send them as text, one per message.
- Set a target for a currency pair and get a notification when the rate reaches it. Checked hourly on our side, so it works with the app closed; each alert fires once.
- Transfers between accounts: correcting which account the money went to now works, everyone in a shared account sees the transfers that touch it, and you can record one offline.
```
