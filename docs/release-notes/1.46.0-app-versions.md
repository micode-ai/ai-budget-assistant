# Release notes for admin -> App Versions - 1.46.0

Store / in-app `UpdatePrompt` release notes for version **1.46.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.46.0:
- Write to the developer right from the app: Settings → "Write to the developer".
- Write in any language: replies arrive in your app language, with the original one tap away.
- A push tells you when a reply comes in.
```

## ru

```
Что нового в 1.46.0:
- Пишите разработчику прямо из приложения: Настройки → «Написать разработчику».
- На любом языке: ответ придёт на языке приложения, оригинал — одним нажатием.
- О новом ответе сообщит push-уведомление.
```

## ua
