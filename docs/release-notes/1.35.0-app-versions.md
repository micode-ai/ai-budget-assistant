# Release notes for admin -> App Versions - 1.35.0

Store / in-app `UpdatePrompt` release notes for version **1.35.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

**The balance correction leads**, because it is the one new thing a user can do right away.
The faster-capture tip follows, then the three app-side fixes.

**Deliberately NOT listed:** the income-category and deposit-receipt fixes (ABA-666,
ABA-664), community price reads (ABA-642, ABA-662) and the short group link (ABA-649) —
server-side, already live for every app version; web-only telemetry (ABA-683) and the
admin funnel (ABA-680).

---

## en

```
What's new in 1.35.0:
- Wallet: correct a balance by entering the real amount. Only the wallet changes, not your spending.
- A one-time tip on faster ways to add expenses after 10 typed by hand.
- Categories no longer get swapped when an edit syncs.
- Receipt lines show their quantity.
- Bank-notification expenses (Android) are named by the shop only.
```
