# Release notes for admin -> App Versions - 1.36.0

Store / in-app `UpdatePrompt` release notes for version **1.36.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

**Subcategories lead**, because they are what a user can do right away; drag and drop and the
analytics drill-down follow, then standard categories following the app language.

**Deliberately NOT listed:** no duplicate auto-created categories (ABA-696, server side) and
the deposit category found in any language (ABA-697, ABA-698) — server-side, already live for
every app version.

---

## en

```
What's new in 1.36.0:
- Subcategories: put Bread or Snacks under Groceries, Beer or Wine under Alcohol. Budgets count them in the parent and show the breakdown.
- Settings → Categories: drag a category onto another to nest it, or between categories to move it back.
- Analytics: tap a category to see its subcategories.
- Income categories get subcategories too.
- Standard categories follow the app language.
```
