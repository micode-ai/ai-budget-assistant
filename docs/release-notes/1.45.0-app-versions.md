# Release notes for admin -> App Versions - 1.45.0

Store / in-app `UpdatePrompt` release notes for version **1.45.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.45.0:
- Privacy mode: hide all amounts with one tap.
- Saved views for searches and filters.
- A calculator in the amount field.
- Credit cards: this cycle's spend, dates and a payment reminder.
- A monthly cap per merchant and a "spend less than" budget shortcut.
- Utility readings, quiet hours for pushes, German bank imports.
```
