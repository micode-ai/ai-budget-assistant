# Release notes for admin -> App Versions - 1.33.0

Store / in-app `UpdatePrompt` release notes for version **1.33.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

**The shopping list leads**, because per-item prices and the shelf price-tag scan are
the new features of this version. The account-switch fix follows because it is what a
user of several accounts noticed most. Most of the other fixes in this version are on
the server and already work in older app versions.

**Deliberately NOT listed:** the chat-prompt and AI reworks, the backup restore, the
Telegram webhook secret, the wallet month boundaries and the admin dashboard (all
server-side, already live); the ActionResultCard split (ABA-621) and the prompt audit
of the developer tooling (ABA-626) — no user-visible change.

---

## en

```
What's new in 1.33.0:
- Shopping list: a price for each item, running totals, and scan a shelf price tag to add an item.
- Switching accounts no longer leaves the previous account's wallet balances on the home screen.
- Chat history shows only the conversations of the current account.
- Saved what-if scenarios stay private to you and the account.
- Pull to refresh always syncs, and About shows the build number.
```
