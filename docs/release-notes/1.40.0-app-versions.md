# Release notes for admin -> App Versions - 1.40.0

Store / in-app `UpdatePrompt` release notes for version **1.40.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.40.0:
- Children's costs: assign expenses or receipt lines to a child, see the 800+ coverage, Pro PDF statement.
- Promo leaflets: share a leaflet and see which deals match what you usually buy.
- Long receipts: shoot 2–4 overlapping photos, get one expense.
- A receipt scan that duplicates a typed expense is offered as a merge.
- Offline expenses and deletes now sync reliably.
```
