# Release notes for admin -> App Versions - 1.38.1

Store / in-app `UpdatePrompt` release notes for version **1.38.1**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.38.1:
- Share a payment SMS, e-mail or chat message into the app to prefill an expense.
- Long-press the app icon: Add expense, Scan receipt, Voice.
- New currencies: CZK, SEK, NOK, DKK, HUF, RON, CHF.
- Shared accounts: spending per member in Analytics.
- "Normal for me" mutes an alert that keeps coming back.
- Try the app with sample data; see changes still waiting to sync.
- Fixes: launcher shortcuts open once; sync chip count.
```
