# Release notes for admin → App Versions — 1.15.0

Store / in-app `UpdatePrompt` release notes for version **1.15.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

---

## en

```
New in 1.15.0:
• Make the app yours — pick an accent color on top of the light or dark theme, from ready-made presets or a custom color picker. It works in both modes and syncs across your devices.
• Inflation Shield now gives you a heads-up — a friendly reminder about the top product worth stocking up on before its price rises.
• Various polish and stability improvements.
```
