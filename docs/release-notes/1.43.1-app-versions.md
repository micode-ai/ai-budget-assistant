# Release notes for admin -> App Versions - 1.43.1

Store / in-app `UpdatePrompt` release notes for version **1.43.1**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.43.1:
- Fixed: with Portuguese as the app language, the home screen showed an error right after sign-in.
- Pets: category rules — expenses in a chosen category go to your pet automatically.
- A pet field on the expense screen.
```
