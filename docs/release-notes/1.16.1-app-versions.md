# Release notes for admin → App Versions — 1.16.1

Store / in-app `UpdatePrompt` release notes for version **1.16.1**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

---

## en

```
Fixed in 1.16.1:
• The spending audit and the spending story are now always shown in your display currency, with every amount converted into it — before, one small charge in another currency could make a whole account read in dollars.
• Bank notification auto-capture no longer invents expenses out of price alerts, balance updates, rate alerts and declined payments.
• Auto-capture now recognises amounts written as "12,34 EUR", so card payments from banks outside Poland are no longer skipped.
```

## ru
