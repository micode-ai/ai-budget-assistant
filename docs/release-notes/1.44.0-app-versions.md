# Release notes for admin -> App Versions - 1.44.0

Store / in-app `UpdatePrompt` release notes for version **1.44.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.44.0:
- All accounts: spending, income and net for any period across all your accounts, with a line per account and a monthly chart.
- Same-named categories add up across accounts.
- Account groups (Pro): compare accounts side by side, e.g. your properties.
- One report (CSV, Excel, PDF) for all accounts or a group, with subtotals per account.
```

## ru

```
Что нового в 1.44.0:
- Все аккаунты: расходы, доходы и итог за любой период по всем аккаунтам, строка на каждый аккаунт и график по месяцам.
- Категории с одинаковым названием складываются между аккаунтами.
- Группы аккаунтов (Pro): сравнение аккаунтов бок о бок, например объектов недвижимости.
- Один отчёт (CSV, Excel, PDF) по всем аккаунтам или группе с подытогами.
```

## ua
