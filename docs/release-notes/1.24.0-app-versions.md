# Release notes for admin -> App Versions - 1.24.0

Store / in-app `UpdatePrompt` release notes for version **1.24.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**An `app_versions` row SHOULD be created for this version** — unlike 1.23.1,
which was a layout fix with nothing to invite anyone to update *for*. Rate alerts
getting their own screen is a reason to open the app, so the in-app prompt should
serve 1.24.0.

**The copy leads with rate alerts, not with the referral link.** The referral fix
matters more to us than to the person reading the note: for them it is "the
invite works properly now", which is not a reason to update. The rate-alerts
screen is something they can go and use.

**It does not mention the store-rating prompt.** Telling people "we will ask you
to rate the app" in the release notes is asking twice, and the first ask is the
one that converts.

**"Already triggered" is stated explicitly.** That alert state was previously
invisible in the app at all — someone who set an alert and never saw it fire has
been quietly waiting, and this is the line that tells them where it went.
