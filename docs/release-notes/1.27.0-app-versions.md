# Release notes for admin -> App Versions - 1.27.0

Store / in-app `UpdatePrompt` release notes for version **1.27.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Sharing one item leads, because it is the thing people asked for.** Until now a
bill could only be divided by giving each line to exactly one person, which meant
a bottle of wine shared by the table had nowhere to go. The line about it is
written as a capability ("tap everyone who had it"), not as a fix, because
nothing was broken — it simply could not be expressed.

**The guest-page amount is described as what the friend sees, not as a bug we
fixed.** Saying "each line now shows their share" tells a payer what their friend
will read; saying "we were printing the full price" would only worry someone who
never noticed, and before this release no line could be shared anyway, so no one
ever saw a wrong number.

**The QR fix is stated plainly and early.** It is the one item in this release
that was visibly broken for a real user: every scanned code opened an error page.
People who hit it need to know it works now, and people who never tried it are
told what the feature is at the same time.

**"Check the receipt" is framed as the friend's reassurance, not as our
transparency.** The useful sentence is that they can open the photo themselves, so
they are not taking a number on trust.

**Keyboard shortcuts name the two keys worth remembering and stop.** Listing all
seven would be a manual; `/` to search and `n` to add are the ones that change how
a session feels, and `?` is how someone finds the rest.

**A minor, not a patch.** Sharing an item, the recurring-bill nudge and desktop
shortcuts are all new capability, so 1.27.0 rather than 1.26.1 — the same
reasoning as the previous two bumps.

## en

```
New in 1.27.0:
- A receipt item can now be shared between several people. Tap the item, then tap everyone who had it — a shared line is divided equally between them, and tapping someone again takes them off.
- Each friend's link now shows their own share of every line rather than its full price, so the lines always add up to the amount they're being asked for. A shared line is marked as such.
- Your friend can now open the receipt itself from their link, if you scanned one, and check the bill rather than take your figures on trust.
- Fixed: scanning the QR code for a bill split opened an error page instead of the list of names. Codes you already showed people work now too.
- When the app spots a bill you pay every month, the alert now offers to mark it as recurring in one tap, so it is counted as a fixed cost instead of skewing your forecast.
- Shopping list items are now ticked off automatically when you scan a receipt containing them. You can undo it straight from the message, or turn it off in Settings → Data.
- In a browser: press / to search your transactions, n to add one, and ? to see every shortcut.
```

## es

```
Novedades en 1.27.0:
- Un artículo del recibo ahora se puede repartir entre varias personas. Toca el artículo y luego marca a todos los que lo tomaron: el precio se divide a partes iguales entre ellos, y al tocar de nuevo a alguien lo quitas.
```
