# Release notes for admin -> App Versions - 1.34.0

Store / in-app `UpdatePrompt` release notes for version **1.34.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

**Shared groups lead**, because they are the new feature of this version and the one a
user can try with friends right away. Month in review and the import-first onboarding
follow.

**Deliberately NOT listed:** forwarding e-receipts by e-mail (ABA-644) and the community
price map (ABA-642), both shipped dark behind server flags; adding a group expense from
the bots (ABA-658) and the Monefy import fix (ABA-637), server-side and already live; the
iPhone install guide (ABA-645) and the desktop layouts (ABA-646), web only; the short
group link (ABA-649), not yet activated.

---

## en

```
What's new in 1.34.0:
- Shared groups: split ongoing costs with friends by a link or QR code, no app needed for them.
- Groups handle other currencies, receipt lines, partial payments and weekly reminders.
- Count your share of group expenses in your own budget.
- Month in review: a monthly Wrapped deck on the 1st.
- New accounts start with a bank statement import and a 3-month report.
```
