# Release notes for admin -> App Versions - 1.42.0

Store / in-app `UpdatePrompt` release notes for version **1.42.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.42.0:
- Analytics: 30-day forecast, year over year, a spending calendar, net worth across accounts, fixed vs flexible costs.
- Your financial month (from payday) is followed across the app.
- Car costs: fuel, service, insurance, parking — with or without litres.
- Children: categories that count for a child; move a child or car to another account.
```

## ru

```
- Финансовый месяц (от зарплаты) учитывается во всём приложении.
- Расходы на машину: топливо, сервис, страховка, парковка — с литрами или без.
- Дети: категории ребёнка; перенос ребёнка или машины в другой счёт.
```
