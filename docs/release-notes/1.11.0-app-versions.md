# Release notes for admin → App Versions — 1.11.0

Store / in-app `UpdatePrompt` release notes for version **1.11.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

---

## en

```
New in 1.11.0:
• Group Trip Wallet — a new "Trip" account for travel groups: split expenses, see who owes whom, and settle up with Revolut/PayPal/BLIK links.
• Personal Inflation Index — track how your own prices change over time from scanned receipts; compare stores and per-product trends.
• Expense map — see where you spent; scanned receipts are placed automatically, or drop a pin by hand. New List/Map toggle and Trip map.
• Invite people to shared accounts by searching their name or email.
• Per-category budget alerts; plus store-address and map-pin fixes.
```
