# Release notes for admin -> App Versions - 1.30.0

Store / in-app `UpdatePrompt` release notes for version **1.30.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit**, unlike
1.29.0's, which were written for the in-app prompt and run to ~900. The builder
that produced this file asserts the limit per locale, so a future edit that
overruns it fails rather than being silently truncated by the Console.

**The category fix leads, because it is what people actually lost.** It is
written as "the categories you assign now stick", not as a sync bug: the user's
experience was that a category they had set was simply not there any more, and
on a category budget the figure appeared and then fell to zero.

**Nothing claims the already-lost assignments come back.** Where a category was
erased before this build, the phone re-sends whatever it still holds, but
anything gone from both sides has to be set again - so the notes promise
behaviour from now on, not recovery.

**Deliberately NOT listed:** the `expense_items.line_discount` migration
(ABA-558) and the category-rename 500 (ABA-565) were server-side faults already
fixed in production before this build ships - announcing them would describe
failures no user of this version can encounter. The Play Install Referrer work
(ABA-553), the CI/build repairs (ABA-563) and the marketing-site badge (ABA-555)
are invisible to users.

---

## en

```
What's new in 1.30.0:
- Categories you assign now stick. Edits survive a restart and reach your other devices.
- A budget for a category shows the real amount instead of dropping to zero after a refresh.
- Budgets update as soon as you add an expense.
- Receipt scanning reads discount lines correctly, and split shares are based on what you actually paid.
- New "Without category" filter, and you stay signed in for longer.
```
