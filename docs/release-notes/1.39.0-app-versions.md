# Release notes for admin -> App Versions - 1.39.0

Store / in-app `UpdatePrompt` release notes for version **1.39.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.39.0:
- Settings → Share AI Budget: send the app to a friend in one tap.
- Getting started leads with a receipt scan, the fastest first entry.
- A budget no longer needs a name — it is filled in for you.
- Shared images always show ai-budget.pl.
- Small fixes and improvements.
```
