# Release notes for admin -> App Versions - 1.19.0

Store / in-app `UpdatePrompt` release notes for version **1.19.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

**This file supersedes `1.18.0-app-versions.md`, which was never used.** 1.18.0's
submit was rejected by Google Play over the foreground-service declaration, and
the admin App Versions table still reports **1.17.0** as the latest registered
version — so users are updating from 1.17.x and have never seen 1.18.0's work.
These notes therefore carry both releases.

**The store-arrival card and shopping mode are deliberately absent.** They were
announced in 1.18.0's unused notes and have since been held back (ABA-438), so
mentioning them would promise something this build does not contain.

**The report-period fixes are described as what you get, not as what was broken.**
"Your reports used to cover the wrong dates" is true and unsettling for someone
who has already filed one; the fix is stated positively instead.

---

## en

```
New in 1.19.0:
- Scanned receipts split across categories automatically. A supermarket trip arrives as groceries, household and alcohol instead of one lump, and you can move any line before saving. It learns from your corrections.
- Moving from Monefy, Wallet by BudgetBakers or Money Manager? Their exports import in one tap, bringing your old categories with them.
- Reports cover exactly the dates you pick: choose a preset, a specific month or your own range, and see the resolved dates before you generate. Export now works in the browser too.
- Report PDFs no longer mix currencies - every figure is converted to your display currency.
- Your wallet now shows every currency your account actually holds money in, not just the ones with a starting balance.
```

## ru

```
Что нового в 1.19.0:
- Отсканированные чеки сами раскладываются по категориям. Поход в супермаркет приходит как продукты, бытовая химия и алкоголь, а не одним комком, и любую строку можно перенести до сохранения. Приложение учится на ваших исправлениях.
- Переходите с Monefy, Wallet by BudgetBakers или Money Manager? Их выгрузки импортируются в одно касание вместе с вашими прежними категориями.
- Отчёты охватывают ровно те даты, которые вы выбрали: пресет, конкретный месяц или свой диапазон, и итоговые даты видны до формирования. Экспорт теперь работает и в браузере.
- В PDF-отчётах больше не смешиваются валюты - все суммы пересчитываются в вашу валюту отображения.
- Кошелёк показывает каждую валюту, в которой у аккаунта реально есть деньги, а не только те, где задан начальный баланс.
```
