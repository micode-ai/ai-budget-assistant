# Release notes for admin -> App Versions - 1.37.0

Store / in-app `UpdatePrompt` release notes for version **1.37.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.37.0:
- Zoom into a receipt: tap a receipt photo on a transaction or on the scan confirmation screen, pinch to zoom up to 5×, double-tap to zoom in and back, drag to move around.
```
