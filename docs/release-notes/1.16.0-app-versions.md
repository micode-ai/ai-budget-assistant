# Release notes for admin → App Versions — 1.16.0

Store / in-app `UpdatePrompt` release notes for version **1.16.0**, one block per
locale. Paste each into the matching field in the admin **App Versions** form
(EN is required; the other 8 are optional). Locales: `en`, `ru`, `ua`, `pl`,
`es`, `fr`, `de`, `be`, `nl`.

---

## en

```
New in 1.16.0:
• Your month can now start on payday — if your salary arrives on the 10th, set your account's financial month to the 10th and budgets run from the 10th to the 9th instead of the calendar month.
• Pick the date while adding an expense or income, instead of saving it as today and fixing it afterwards.
• Change an expense's currency if it was recorded in the wrong one.
• Fixed: budget history skipped a month when opened on the 29th–31st.
• Fixed: date fields did nothing in the web app.
```
