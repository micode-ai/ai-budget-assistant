# Release notes for admin -> App Versions - 1.43.0

Store / in-app `UpdatePrompt` release notes for version **1.43.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.43.0:
- Pets: track what each pet costs, with vaccination and flea & tick reminders.
- Cars: insurance, inspection and service reminders; a vehicle screen with costs by month.
- A petrol-station receipt fills in the fill-up — just add the odometer.
- Security improvements.
```
