# Release notes for admin -> App Versions - 1.47.0

Store / in-app `UpdatePrompt` release notes for version **1.47.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`, `pt`, `br`.

**Every block is under Google Play's 500-character "What's new" limit.**

---

## en

```
What's new in 1.47.0:
- An unread reply from the developer also arrives by e-mail.
- New help sections: AI assistant connector (MCP) and Utilities.
- "Share usage statistics" (Settings → Security & Encryption) shows us which features are used. Never amounts or what you write; turn it off any time.
```
