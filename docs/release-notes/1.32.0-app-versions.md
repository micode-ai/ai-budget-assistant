# Release notes for admin -> App Versions - 1.32.0

Store / in-app `UpdatePrompt` release notes for version **1.32.0**, one block per
locale. Locales: `en`, `ru`, `ua`, `pl`, `es`, `fr`, `de`, `be`, `nl`.

**Every block is under Google Play's 500-character "What's new" limit**; the
builder that produced this file asserts it per locale.

**Real salary leads**, because it is the headline feature of this version; sharing a
receipt from another app follows as the biggest time-saver on Android. The voice
digest is listed last: it lives in the chat bots and works without this app update.

**Deliberately NOT listed:** the smaller real-salary fixes (ABA-611, ABA-612, ABA-617,
ABA-618) — they refine a feature new to this version — the voice-digest wording fix
(ABA-614), the technical docs (ABA-616) and the marketing-site work (ABA-584).

---

## en

```
What's new in 1.32.0:
- Real salary: see if your pay keeps up with your own inflation, with a PDF brief for a raise talk.
- Share a receipt photo, screenshot or PDF from any app to add it as an expense.
- Mark an existing expense as recurring while editing it.
- Tap an expense in a chat answer to open it, and search the Help center.
- Weekly voice summary in Telegram, WhatsApp and Slack: /digest on.
```
