## Сезонный календарь — когда что запускать

Половина пунктов выше конвертит в разы лучше в своё окно. Один и тот же рил,
выпущенный в сезон, стоит дешевле за установку.

| Окно | Что запускать | Почему |
|---|---|---|
| **Январь–апрель** | Отчёты / экспорт (10), «zestawienie dla księgowej» | Сезон PIT. Пик темы «отдать бухгалтеру» — в августе тот же рил работает вхолостую |
| **Декабрь–январь** | Wrapped (рил есть) — перезапуск | Итоги года; все привыкли к формату по Spotify |
| **Август** | Список покупок + чек-контроль (2), «wyprawka szkolna» | Польская школа стартует 1 сентября, закупка идёт 15–31 августа. Блог-статья `school` уже написана в 9 языках |
| **Сентябрь** | Бюджеты, конверты, financial month | Возврат к рутине после отпусков |
| **Ноябрь (Black Friday)** | Чек-контроль (2) + список покупок + личная инфляция | Месяц, когда «дороже, чем обычно» проверяют все |
| **Начало месяца / после зарплаты** | Safe-to-Spend (1), financial month | Вопрос «сколько можно потратить» задаётся именно тогда |
| **Ослабление злотого** | Кошелёк + кантор (9, готово) | Курсы сами входят в разговоры; окно непредсказуемое, держать креатив наготове |
| **Круглый год** | Авто-захват push (3), авто-разбивка чека (13), переезд из другого приложения (15) | Сезона нет — это базовые USP |

## Сценарные связки под персону

«Сценарные reels по персонам» ниже перечислены как неиспробованный формат.
Конкретные связки, которые уже можно собрать из готовых фич:

- **Фрилансер с доходом в EUR** → кошелёк + кантор + отчёт для бухгалтера + импорт из любого банка.
  Самая платёжеспособная персона; естественный апселл на Business (недельный e-mail).
- **Семья с детьми** → общий счёт + семейная лента + запросы на покупку + авто-разбивка чека.
  Здесь **нельзя** упоминать переводы между счетами: их видит только автор.
- **Диаспора (UA / BY)** → кошелёк PLN+UAH + приложение на 9 языках + переводы между своими счетами.
  UAH и BYN в списке валют — не случайность, это готовое попадание.
- **Переезжающий с другого приложения** → миграция из Monefy/Wallet/1Money + импорт выписки + «твои данные твои» (бэкап и экспорт бесплатны).
- **Студент / первая работа** → Safe-to-Spend + список покупок + чек-контроль. Всё бесплатное, ничего про Pro.

## Форматы под конкретный пункт

К общему списку форматов ниже — что чем лучше снимать:

- **«До / после» в одном кадре** — авто-разбивка чека (13): один блоб → три категории. Самый наглядный формат из всех доступных.
- **Экран телефона без монтажа** («сними, как оно есть») — авто-захват push (3): оплата картой, уведомление банка, расход уже в приложении.
- **Разговор в мессенджере как хук** — отчёты (10, «Prześlij mi zestawienie»), запросы на покупку.
- **Карусель из блога** — 21 тема × 9 языков уже написаны; переиспользовать почти бесплатно.

## Что сейчас рекламировать нельзя

- **Карта цен сообщества (Pro)** — чтение за kill-switch `COMMUNITY_PRICE_READ_ENABLED`
  (по умолчанию OFF), анти-Sybil не закрыт (`docs/superpowers/community-price-antisybil.md`).
  В релиз-ноутах 1.13.0 её уже анонсировали — **перед кампанией проверить флаг в прод-env**,
  иначе человек придёт на пустой экран.
- **Счётчик «найдено переплат» в аналитике и алерт-карточка чек-контроля** — за
  `RECEIPT_CHECK_ALERTS_ENABLED` (по умолчанию OFF, `docs/ops/receipt-price-check-rollout.md`).
  Рекламировать только предупреждение на экране сканирования.
- **Формулировки чек-контроля**: только «дороже, чем обычно — проверь чек».
  Нельзя «тебя обманули / промо не сработало» — данных, что промо было, у нас нет.
- **iOS не обещать** — App Store ID всё ещё placeholder, ссылки везде на Google Play.

## Как выпускается одна кампания

1. Скриншоты: положить в `creatives/<name>/` (источники — как есть с телефона).
2. Копирайт: `copy/feature-<name>-reel-pl.md` — сториборд (таблица: # / время / что показываем /
   текст на экране), подпись к посту, хэштеги, короткий вариант для Stories. **На польском**
   (см. `copy/feature-antinflation-reel-pl.md` как эталон).
3. Генератор: `scripts/build_<name>_reel.py` по образцу `build_purchase_list_reel.py` /
   `build_antinflation_reel.py`; рендер в `creatives/<name>/renders/pl/`.
4. Прогон: `python docs/marketing/scripts/build_<name>_reel.py both` и `... both 4:5`
   (9:16 для Reels/Stories, 4:5 для фида).
5. Отметить пункт в таблице выше как `done`.
