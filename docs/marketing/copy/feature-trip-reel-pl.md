# AI Budget Assistant — Reel „Portfel podróży" (Instagram / Facebook Reels)

Nowa funkcja: **Portfel podróży** (Group Trip Wallet) — wspólne konto na wyjazd dla grupy. Dodajesz wspólne wydatki, dzielisz je (po równo / dokładne kwoty / procentowo / udziały), a na koniec aplikacja liczy, kto komu ile jest winien, i podpowiada rozliczenie (Revolut / PayPal / BLIK).

Format: pionowy 9:16 (1080×1920) + wersja 4:5 do feedu, ~29 sek. Konto: profil AI Budget Assistant.
Link: https://play.google.com/store/apps/details?id=com.budget.assistant · app.ai-budget.pl

Render: `python build_trip_reel.py both` (+ `4:5`) → `creatives/trip/renders/pl/`
