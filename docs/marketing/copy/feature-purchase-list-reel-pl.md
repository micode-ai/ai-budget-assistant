# AI Budget Assistant — Reel „Lista zakupów" (Instagram / Facebook Reels)

Nowa funkcja: **Inteligentna lista zakupów** — twórz listę, dostawaj podpowiedzi „czas na uzupełnienie zapasów", a przed wyjściem sprawdź, w którym sklepie kupisz cały koszyk najtaniej — także na mapie, według ceny lub odległości.

Ważne: porównanie cen liczone jest **na podstawie Twoich własnych zeskanowanych paragonów** (Twojej osobistej historii cen), a nie zewnętrznej bazy — im więcej paragonów skanujesz, tym dokładniejsze wyniki.

Format: pionowy 9:16 (1080×1920) + wersja 4:5 do feedu, ~28–30 sek. Konto: profil AI Budget Assistant.
Link: https://play.google.com/store/apps/details?id=com.budget.assistant · app.ai-budget.pl

Render: `python build_purchase_list_reel.py both` (+ `4:5`) → `creatives/purchase-list/renders/pl/`
