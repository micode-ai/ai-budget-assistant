# AI Budget Assistant — Reel „Cele oszczędnościowe" (Instagram / Facebook Reels)

Funkcja: **Cele oszczędnościowe** — wyznacz cel (np. wakacje, poduszka finansowa, nowy sprzęt), a aplikacja pokaże postęp, oceni, jak realny jest cel, i **poprosi AI o gotowy plan oszczędzania** — ile odkładać miesięcznie i tygodniowo oraz w których kategoriach warto ograniczyć wydatki.

Ważne: prognoza „W normie / kiedy osiągniesz cel" i **plan AI** liczone są **na podstawie Twoich realnych wydatków i dochodów** w aplikacji — im dokładniej śledzisz budżet, tym trafniejszy plan.

Format: pionowy 9:16 (1080×1920) + wersja 4:5 do feedu, ~26–28 sek. Konto: profil AI Budget Assistant.
Link: https://play.google.com/store/apps/details?id=com.budget.assistant · app.ai-budget.pl

Render: `python build_goals_reel.py both` (+ `4:5`) → `creatives/goals/renders/pl/`
