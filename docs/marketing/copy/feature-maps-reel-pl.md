# AI Budget Assistant — Reel „Mapa wydatków" (Instagram / Facebook Reels)

Nowa funkcja: **Mapa wydatków** — zobacz swoje wydatki na mapie. Zeskanowany paragon sam ustawia lokalizację sklepu (z adresu na paragonie), a Ty możesz też postawić pinezkę ręcznie.

Format: pionowy 9:16 (1080×1920) + wersja 4:5 do feedu, ~16–18 sek. Konto: profil AI Budget Assistant.
Link: https://play.google.com/store/apps/details?id=com.budget.assistant · app.ai-budget.pl

Render: `python build_maps_reel.py both` (+ `4:5`) → `creatives/maps/renders/pl/`
