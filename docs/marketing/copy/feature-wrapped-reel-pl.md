# AI Budget Assistant — Reel „Podsumowanie roku" (Instagram / Facebook Reels)

Funkcja: **Podsumowanie roku** (Financial Wrapped) — Twój rok w liczbach w stylu Spotify Wrapped: ulubione sklepy, największy miesiąc, top kategorii, liczba zeskanowanych paragonów, najdłuższa passa śledzenia i stopa oszczędności. Przesuwasz kolejne karty i **udostępniasz** swój rok jednym dotknięciem (z opcją „Ukryj kwoty").

Ważne: podsumowanie budowane jest **w całości z Twoich danych w aplikacji** — nie wymaga żadnej dodatkowej konfiguracji, jest **darmowe** i gotowe do udostępnienia.

Format: pionowy 9:16 (1080×1920) + wersja 4:5 do feedu, ~28–30 sek. Konto: profil AI Budget Assistant.
Link: https://play.google.com/store/apps/details?id=com.budget.assistant · app.ai-budget.pl

Render: `python build_wrapped_reel.py both` (+ `4:5`) → `creatives/wrapper/renders/pl/`
