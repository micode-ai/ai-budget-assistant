# Community post log

One row per community post that actually went out, with how it did, so "does posting in
communities work for us?" gets answered from our own posts. Written by the `community-post`
skill when the user says a post is live; safe to hand-edit. The target list with statuses is
`docs/marketing/backlinks-tracker.csv` — this file records outcomes.

**Columns.** `Where`: the community (`r/PolskaFinanse`, `Wykop #finanse`, a Facebook group
name, `Show HN`). `Post`: a short label. `Verdict`: the Go/No-Go it went out under — `Go`,
`Go (hedged)` for a Go resting on secondary or user-supplied rules, `No-Go` if posted anyway.
`Removed`: `no`, or `moderator` / `automod` / `spam filter` / `deleted`. `Score`: upvotes or
reactions; `Comments`; `Views` where shown. Leave a cell blank when unknown, never guess. Fewer
than 5 posts in a group is "too few to tell".
