Alertas: atividade incomum

O app acompanha seus gastos e avisa você quando algo parece fora do normal — sem nenhuma configuração. Toque no ícone de sino na tela inicial para ver todos os alertas.

O que o app detecta

  • Possível cobrança duplicada — o mesmo estabelecimento cobrou o mesmo valor duas vezes em dois dias. Vale a pena conferir antes que o dinheiro vá embora. Quando um dos registros veio de uma notificação ou importação do banco e o outro é um recibo escaneado, o alerta também oferece mesclar os dois: toque nele para abrir a tela de mesclagem, e os itens e a imagem do recibo passam para a despesa que você mantiver.
  • Aumento de preço — uma assinatura ou pagamento recorrente ficou mais de 10% mais caro do que da última vez (por exemplo, um serviço de streaming que aumentou o preço).
  • Parece uma assinatura — o mesmo estabelecimento cobrou de você o mesmo valor três ou mais vezes, em intervalos regulares. Você tem duas opções: tocar no alerta para abrir um formulário já preenchido do Gerenciador de assinaturas, ou tocar em “Marcar como recorrente” direto no alerta, para que essa despesa (o aluguel é um exemplo comum) passe a ser tratada como uma conta recorrente — assim ela deixa de bagunçar todo mês a previsão de gastos do seu orçamento.
  • Gastos incomuns — uma categoria está pelo menos 30% acima da sua média dos meses anteriores.

Como os alertas chegam até você

  • Você recebe uma notificação push quando uma anomalia é encontrada (no máximo 3 por dia, para o seu celular nunca ficar lotado).
  • Todo alerta também fica salvo no feed de alertas — toque no ícone de sino na tela inicial. Na versão web, você vê o mesmo feed.
  • Toque em um alerta para abrir a despesa relacionada, marque alertas como lidos ou dispense-os com o botão ✕.

Configurações

Você pode ativar ou desativar as notificações push de anomalias em Configurações → Notificações → Alertas de anomalias. O feed de alertas continua funcionando mesmo com as notificações push desligadas.

Bom saber

  • A detecção funciona automaticamente para despesas adicionadas manualmente, por voz, a partir de recibos, pelos bots de Telegram/WhatsApp/Slack e por importação bancária.
  • Cada anomalia é avisada uma única vez — você nunca recebe o mesmo alerta duas vezes.
  • Depois que você resolve uma possível duplicação, excluindo ou mesclando a despesa a mais, o alerta some sozinho. Se você já tinha resolvido, ao tocar no alerta ele simplesmente mostra que está resolvido — nada de uma tela confusa de “despesa não encontrada”.
  • Em contas compartilhadas, marcar alertas como lidos vale para a conta inteira; visualizadores podem ler o feed, mas não alterá-lo.
  • Normal para mim: em um cartão de alerta, toque em Normal para mim para parar de receber esse tipo de alerta para aquele estabelecimento ou categoria. Os outros tipos de alerta continuam chegando. Revise ou desfaça em Alertas → Alertas silenciados.
