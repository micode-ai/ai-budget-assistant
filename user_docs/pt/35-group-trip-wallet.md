# Carteira de viagem em grupo

> Uma conta partilhada temporária para um grupo de viagem — divida as despesas entre os membros e acerte contas no fim da viagem, para saber quem deve a quem.

## Criar uma viagem

Toque em **Criar conta** e escolha **Viagem**. Dê-lhe um nome, escolha uma data de fim e a moeda em que vai gastar mais. Convide os seus companheiros de viagem da mesma forma que convidaria qualquer pessoa para uma conta partilhada — partilhe o link ou o código de convite.

## Dividir uma despesa

Quando adiciona uma despesa numa conta de viagem, aparece uma secção **Dividir entre** por baixo do valor. Escolha a quem a despesa diz respeito e depois como a dividir:

- **Partes iguais** — o valor é dividido de forma igual pelos membros selecionados.
- **Valores exatos** — indique exatamente quanto cada pessoa deve; os valores têm de somar o total.
- **Percentagem** — indique uma percentagem para cada pessoa; as percentagens têm de somar 100%.
- **Quotas** — atribua a cada pessoa um número de quotas (por exemplo, 2 quotas para um casal e 1 quota para quem viaja sozinho); o total é dividido proporcionalmente.

Também pode alterar **quem pagou** — por predefinição é quem adicionou a despesa, mas pode escolher outra pessoa se estiver a registar uma compra em nome dela.

## Acertar contas

Toque na viagem no seletor de contas — enquanto a viagem está ativa ou acabou de terminar, verá um selo com os dias restantes em que pode tocar para abrir **Acertar contas**.

O ecrã Acertar contas mostra o número mínimo de pagamentos necessários para equilibrar os saldos de todos. Se deve dinheiro a alguém, toque em **Pagar** — se essa pessoa tiver adicionado um identificador do Revolut ou do PayPal nas definições de pagamento, a aplicação abre um link de pagamento já preenchido. Para BLIK, verá o número de telefone dessa pessoa para fazer a transferência manualmente. Se essa pessoa não tiver configurado nenhum método de pagamento, basta marcar a dívida como acertada depois de lhe pagar de outra forma.

Se alguém lhe deve dinheiro, depois de essa pessoa pagar, toque em **Confirmar receção** para retirar a dívida do saldo.

## Indicar os seus dados de pagamento

Abra **Definições de pagamento** a partir do ecrã da conta de viagem para indicar como os outros lhe devem pagar — um nome de utilizador do Revolut ou do PayPal, ou o seu número de telemóvel para BLIK.

## Ciclo de vida da viagem

Uma viagem tem três estados:

- **Ativa** — a viagem está a decorrer. As despesas podem ser adicionadas e editadas normalmente.
- **Em acerto** — a data de fim da viagem já passou. Recebe um lembrete para acertar contas. Ainda é possível adicionar despesas, caso esteja a pôr em dia os últimos dias.
- **Arquivada** — o proprietário da viagem encerrou-a. A conta passa a ser só de leitura para sempre, guardada como registo da viagem. Normalmente, arquivar exige que todas as dívidas estejam confirmadas, mas o proprietário pode forçar o encerramento se for preciso.

Só o proprietário da viagem pode arquivá-la, a partir do ecrã da conta de viagem.

## Notificações

Recebe um lembrete quando uma viagem termina e chega a hora de acertar contas. Pode desativá-lo em **Definições → Notificações**.
