# Alertas: atividade invulgar

> A aplicação acompanha os seus gastos e avisa quando algo parece invulgar — sem qualquer configuração. Toque no ícone do sino no ecrã inicial para ver todos os alertas.

## O que a aplicação deteta

- **Possível cobrança duplicada** — o mesmo comerciante cobrou o mesmo valor duas vezes no espaço de dois dias. Vale a pena verificar antes que o dinheiro desapareça. Quando um dos registos veio de uma notificação ou importação bancária e o outro é um talão digitalizado, o alerta também propõe **juntá-los**: toque nele para abrir o ecrã de junção, e os artigos e a imagem do talão passam para a despesa que mantiver.
- **Aumento de preço** — uma subscrição ou pagamento recorrente ficou mais de 10% mais caro do que da última vez (por exemplo, um serviço de streaming que sobe o preço).
- **Parece uma subscrição** — o mesmo comerciante cobrou-lhe o mesmo valor três ou mais vezes, com regularidade. Há duas coisas que pode fazer: tocar no alerta para abrir um formulário já preenchido do Gestor de subscrições, ou tocar em **«Marcar como recorrente»** diretamente no alerta, para que essa despesa (a renda é um exemplo comum) passe a ser tratada como uma conta recorrente — assim deixa de distorcer todos os meses a previsão de gastos do seu orçamento.
- **Gastos invulgares** — uma categoria está pelo menos 30% acima da sua média dos meses anteriores.

## Como os alertas lhe chegam

- Recebe uma notificação push quando é detetada uma anomalia (no máximo 3 por dia, para que o telemóvel nunca fique inundado).
- Cada alerta fica também guardado no feed de alertas — toque no ícone do sino no ecrã inicial. Na versão web, vê o mesmo feed.
- Toque num alerta para abrir a despesa correspondente, marque alertas como lidos ou descarte-os com o botão ✕.

## Definições

Pode ativar ou desativar as notificações push de anomalias em **Definições → Notificações → Alertas de anomalias**. O feed de alertas continua a funcionar mesmo com as notificações push desligadas.

## Bom saber

- A deteção funciona automaticamente para despesas adicionadas manualmente, por voz, a partir de talões, através dos bots de Telegram/WhatsApp/Slack e por importação bancária.
- Cada anomalia é comunicada uma única vez — nunca recebe o mesmo alerta duas vezes.
- Depois de resolver uma possível duplicação, eliminando ou juntando a despesa a mais, o alerta desaparece sozinho. Se já tratou do assunto, ao tocar no alerta verá apenas que está resolvido — sem um confuso ecrã de «despesa não encontrada».
- Em contas partilhadas, marcar alertas como lidos afeta toda a conta; os leitores podem consultar o feed, mas não alterá-lo.
- **Normal para mim:** num cartão de alerta, toque em **Normal para mim** para deixar de receber esse tipo de alerta para esse comerciante ou categoria. Os restantes tipos de alerta continuam a chegar. Reveja ou anule em **Alertas → Alertas silenciados**.
