# Carteira de viagem em grupo

> Uma conta compartilhada temporária para um grupo de viagem — divida as despesas entre os membros e acerte as contas no fim da viagem, para saber quem deve a quem.

## Criando uma viagem

Toque em **Criar conta** e escolha **Viagem**. Dê um nome, escolha uma data de término e a moeda em que você vai gastar mais. Convide seus companheiros de viagem do mesmo jeito que convidaria qualquer pessoa para uma conta compartilhada — compartilhe o link ou o código de convite.

## Dividindo uma despesa

Quando você adiciona uma despesa dentro de uma conta de viagem, aparece uma seção **Dividir entre** abaixo do valor. Escolha a quem a despesa se refere e depois como dividi-la:

- **Partes iguais** — o valor é dividido igualmente entre os membros selecionados.
- **Valores exatos** — informe exatamente quanto cada pessoa deve; os valores precisam somar o total.
- **Porcentagem** — informe uma porcentagem para cada pessoa; as porcentagens precisam somar 100%.
- **Cotas** — dê a cada pessoa um número de cotas (por exemplo, 2 cotas para um casal e 1 cota para quem viaja sozinho); o total é dividido proporcionalmente.

Você também pode mudar **quem pagou** — por padrão é quem adicionou a despesa, mas você pode escolher outra pessoa se estiver registrando uma compra em nome dela.

## Acertando as contas

Toque na viagem no seletor de contas — enquanto a viagem estiver ativa ou tiver acabado de terminar, você verá um selo com os dias restantes; toque nele para abrir **Acertar as contas**.

A tela Acertar as contas mostra o número mínimo de pagamentos necessários para zerar os saldos de todo mundo. Se você deve dinheiro a alguém, toque em **Pagar** — se a pessoa tiver adicionado um identificador do Revolut ou do PayPal nas configurações de pagamento, o app abre um link de pagamento já preenchido. Para BLIK, você vê o número de telefone da pessoa para fazer a transferência manualmente. Se ela não tiver configurado nenhuma forma de pagamento, é só marcar a dívida como acertada depois de pagar de outro jeito.

Se alguém deve dinheiro a você, depois que a pessoa pagar, toque em **Confirmar recebimento** para tirar a dívida do saldo.

## Informando seus dados de pagamento

Abra **Configurações de pagamento** na tela da conta de viagem para informar como os outros devem pagar você — um nome de usuário do Revolut ou do PayPal, ou seu número de celular para BLIK.

## Ciclo de vida da viagem

Uma viagem tem três estados:

- **Ativa** — a viagem está em andamento. As despesas podem ser adicionadas e editadas normalmente.
- **Em acerto** — a data de término da viagem já passou. Você recebe um lembrete para acertar as contas. Ainda dá para adicionar despesas, caso você esteja colocando em dia os últimos dias.
- **Arquivada** — o proprietário da viagem a encerrou. A conta fica somente leitura para sempre, guardada como registro da viagem. Normalmente, para arquivar, todas as dívidas precisam estar confirmadas, mas o proprietário pode forçar o encerramento se for necessário.

Só o proprietário da viagem pode arquivá-la, na tela da conta de viagem.

## Notificações

Você recebe um lembrete quando uma viagem termina e chega a hora de acertar as contas. Você pode desativá-lo em **Configurações → Notificações**.
