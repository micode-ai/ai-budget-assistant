# Portuguese glossary — PT-PT (`pt`) and PT-BR (`br`)

The decided terms for the two Portuguese locales. Every string in `pt` uses the left column,
every string in `br` the right one — never mixed inside one file. Used by the mobile locales
(`locales/pt.ts`, `locales/br.ts`), the API copy maps, `user_docs/pt|br/` and the store listings.

Internal codes: `pt` = Português (Portugal), `br` = Português (Brasil). Intl locales are `pt-PT`
and `pt-BR` — never pass `br` raw to `Intl.*` (it reads as Breton).

## Form of address

| | PT-PT (`pt`) | PT-BR (`br`) |
|---|---|---|
| Addressing the user | impersonal or 3rd person; **avoid "você"** — "o seu / a sua", or drop the pronoun ("Ligue a sua conta"). "a sua" always means the reader's: for a third person write "essa pessoa … a parte dela"; avoid gendered "contactá-lo", "o próprio" — prefer "lhe" / "por si" | **"você"**, possessive without article ("Conecte sua conta") |
| Imperative (buttons, instructions) | 3rd person formal: "Abra", "Toque", "Envie" | same: "Abra", "Toque", "Envie" |
| Progressive | "a + infinitive": "A carregar…", "está a gastar" | gerund: "Carregando…", "está gastando" |
| Greeting | "Olá" | "Olá" (not "Oi") |
| Clitics | enclisis: "Envie-nos", "Confirme-o" | proclisis where natural: "nos envie", "o confirme" |
| Spelling | AO1990 (ação, ótimo, receção, facto) | AO1990 Brazilian norm (ação, ótimo, recepção, fato) |
| Quotes | « » | “ ” |
| Decimal / thousands | 1 234,56 (space) | 1.234,56 (dot) |
